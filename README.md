# EDIT.IA — setup da Aula 1

Plugin do Claude Code que prepara o computador do aluno para editar vídeo com IA.

No Claude Code:

```
/plugin marketplace add https://raw.githubusercontent.com/edit-IA/editia/main/.claude-plugin/marketplace.json
/plugin install editia@editia
```

Depois escreva: **prepare meu computador para editar**.
